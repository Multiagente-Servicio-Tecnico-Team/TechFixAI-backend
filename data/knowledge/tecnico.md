# Base de conocimiento - Área Técnica

## Equipo que no enciende
Se debe verificar la conexión eléctrica, cable de alimentación, cargador, batería y fuente de poder.

## Equipo que se apaga
Puede estar relacionado con temperatura elevada, problemas de alimentación o componentes internos.

## Pantalla azul
Puede estar relacionada con fallos de controladores, memoria RAM, sistema operativo o hardware.

## Equipo lento
Se recomienda revisar el consumo de CPU, memoria RAM, almacenamiento disponible y procesos en ejecución.

## Escalamiento
Si las verificaciones iniciales no permiten determinar la causa, se debe realizar un diagnóstico técnico completo.
